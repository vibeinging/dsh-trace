# Security reports

Do not put credentials, original DSH session files, captured Trace copies or sensitive tool output in a public issue. Recording content can include user input and file contents; use synthetic data when reproducing a problem.

For a security issue, use [GitHub's private vulnerability report](https://github.com/vibeinging/dsh-trace/security/advisories/new) if the repository offers it. If private reporting is unavailable, open an issue requesting a private contact without disclosing the vulnerability or sensitive data. Ordinary bugs can use the issue tracker with a sanitized example.

The active plugin targets the versions listed in the README. The archived exporter is not part of the default verification pipeline. This project does not currently promise a response time or long-term support window.
