# Changelog

## 0.1.0 — 2026-10-26

- Waterfall workbench for real DSH session data, live updates and long-history pagination.
- Model/tool details, usage metrics, search, failure filters, focus mode and Chinese/English themes.
- Optional local recording, capture scope, content switches, retention and cleanup previews.
- Trace data management in Settings, with an optional sidebar shortcut.
- Independent open-source workspace, public dependency installation and CI, BSD-3-Clause license and bundled dependency notices.

Distribution: public npm package `@vibeinging/dsh-trace-viewer`. The older yiTrace exporter is retained under `legacy/yitrace-exporter` and is not part of this release's default workspace.
